# August 17, 2026



We are excited to announce a major upgrade to Rova's testing platform, introducing comprehensive support for **API setup & cleanup lifecycle hooks**, an **interactive API testing sandbox**, and several **UX/UI polishing updates** across the test reports and monitoring views.

***

### 🚀 Key Features

#### 1. API Pre-Setup & Post-Cleanup Hooks (Backend & Frontend)

Testers can now programmatically seed databases, authenticate users, or clean up test environments automatically before and after browser runs.

* **Pre-Setup API Calls (`apiPreSteps`):** Executed in sequence prior to launching the browser. If a pre-setup hook fails to validate, the test run aborts early to preserve execution minutes.
* **Post-Cleanup API Calls (`apiPostSteps`):** Executed after a web test execution. They are guaranteed to run unconditionally (even if browser steps fail) to clean up records and tear down sandbox entities.
* **Visual Builder:** Fully editable accordion interfaces in the Advanced Settings panel. Supports HTTP Method, target Endpoint Path (absolute or relative), Header key-value pairs, query parameters, and Request Body types (`json`, `urlencoded`, `form-data`, and `raw`).

#### 2. Standalone API Request Testing Sandbox ("Test Request")

Configure and verify your API hook integrations instantly from the UI without having to run a full browser automation cycle.

* **Inline Previewer:** Clicking the **"Test Request"** button next to any setup or teardown step executes the request immediately on the backend (inheriting active session credentials).
* **Interactive Developer Console:** Displays round-trip response duration, status codes, a formatted and scrollable JSON/text **Response Body** preview, and real-time validation results for your assertions.

#### 3. Dynamic Data Propagation & Variables

* **JSONPath Variable Extractions:** Extract values from JSON response bodies (e.g. `$.auth.token`) and write them to custom variables (e.g. `userToken`).
* **Template Substitution:** Interpolate variables anywhere using `{{variable_name}}` syntax. Placeholders resolve dynamically inside subsequent API URLs, Headers, Body payloads, and browser input fields (e.g., typing token credentials into visual text inputs).

See [documentation](../rova-web/api-testing-in-rova.md) for performing API requests within Rova web tests

### 🎨 User Experience & UI Polishing

#### 1. Step Detail Modal API Inspection View

* We added a full-screen **HTTP Client Console** inside the large left viewport of the **Step Detail Modal** (where screenshots sit for visual browser actions).
* When clicking an `api_request` step in the monitoring timeline, users can now inspect the complete request headers and payloads, and the response headers, body, and assertion validation checklists.

#### 2. Redirect-to-Goal Redirection Update

* When a test execution finishes, the progress action button now changes from **Edit Goal** to **View Goal**.
* When clicked, it redirects you straight to the test's main details view (`/tests/${testId}`) to avoid creating redundant tests or overwriting goal descriptions.

#### 3. Absolute Share Link Dropdown Overlay

* Redesigned the generated share link box from a floating bottom banner into a sleek, vertical overlay card that renders directly underneath the **EXPORT** action button.
* Added a simple dismiss/close button to easily hide the link card after copying it to the clipboard.

#### 4. Email Report Dialog Fixes

* Added single-line truncation to the goal subtitle inside the **Send via Email** modal (`truncate max-w-[240px]`).
* Hovering over truncated goal headers displays the full text as a browser tooltip. This prevents long natural-language descriptions from expanding the dialog header and distorting the inputs layout.

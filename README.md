# Rova Documentation

Welcome to the official documentation for Rova, the AI-first automation platform.

## Main Sections

Rova is divided into three primary components to cover all your automation needs:

1. [**Rova Web**](rova-web/README.md)
   Manage your web tests, suites, schedules, and workspaces. Rova Web provides deep insights into your web application's stability with AI-powered reporting and project context management.

2. [**Rova Mobile**](rova-mobile/README.md)
   Automate iOS and Android applications. Manage mobile goals, execution plans, and app uploads with unified workspace and membership management.

3. [**Rova CLI**](rova-cli/README.md)
   The power of Rova in your terminal. Run tests locally, generate scripts using AI, and integrate Rova into your CI/CD pipelines for both Web and Mobile.
